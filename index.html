Google Drive upload

Nothing to set up — this copy of the app already has its Google details built in. Tap Upload, sign in with your own Google account, and allow access. Your photos stay in your Drive.

The first upload offers to share the Books Curator folder only, read-only, with this address, so the curator can read your shelves without you arranging anything in Drive. You stay the owner and can stop sharing at any time from Drive. Leave it empty and nothing is ever shared.

Normally leave this as Books Curator: the app creates that folder in your own Drive on the first upload and files shelves under Books Curator / _Shelves / <shelf label>. Link… is only for a folder that already exists or was shared with you.

Advanced: use your own Google project

Only needed if this app came without Google details built in, or you want uploads going through a Cloud project you control. Leave every box empty to use whatever the app ships with.

  1. Go to console.cloud.google.com and create a project (any name).
  2. APIs & Services → Library → enable Google Drive API (and Google Picker API if you want Link…).
  3. APIs & Services → OAuth consent screen → External. The app asks only for the non-sensitive drive.file scope, so you can Publish app straight to production with no verification review.
  4. Credentials → Create credentials → OAuth client ID → type Web application; under Authorized JavaScript origins add the address where this app is hosted.
  5. Copy the Client ID (ends in .apps.googleusercontent.com) and paste it below.
  6. For Link… only: Credentials → API key, plus the project number from the Cloud console Dashboard.
