Google Drive upload

Google sign-in is built in. Before your first upload, fill in your name above and the folder name below, then tap Save settings. When you upload, choose your own Google account and tap Allow. Your photos stay in your own Google Drive.

Leave this empty: the app already uses your curator's address, shown in grey. The first upload asks before it shares your upload folder with that address, read-only; nothing else in your Drive is shared. You stay the owner and can stop sharing at any time from Google Drive. If you tap Cancel at that question, nothing is shared and the app does not ask again: tell your curator.

Type the folder name your curator gave you, exactly as written, before your first upload. The app makes that folder in your own Google Drive and files each shelf in it, under _Shelves / <shelf label>. Never change it after your first upload: a new name starts a second folder, and your shelves would be split between the two. Link… is for your curator only.

Advanced — for your curator only

Do not change anything here. On a phone that has uploaded, a different Client ID hides every folder the app made, and your curator's requests stop working. Leave every box empty to use what the app ships with; the steps below are only for a Cloud project of your own.

  1. Go to console.cloud.google.com and create a project (any name).
  2. APIs & Services → Library → enable Google Drive API (and Google Picker API if you want Link…).
  3. APIs & Services → OAuth consent screen → External. The app asks only for the non-sensitive drive.file scope, so you can Publish app straight to production with no verification review.
  4. Credentials → Create credentials → OAuth client ID → type Web application; under Authorized JavaScript origins add the address where this app is hosted.
  5. Copy the Client ID (ends in .apps.googleusercontent.com) and paste it below.
  6. For Link… only: Credentials → API key, plus the project number from the Cloud console Dashboard.
